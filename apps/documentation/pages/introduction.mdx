Welcome to the **MOCA Codex API** — a comprehensive RESTful interface for accessing and managing the MOCA Codex knowledge base. This API provides structured access to curated information about entities, their relationships, and metadata.

<Callout type="note" title="Built on Directus" icon>
  This API is built on **Directus**, an open-source headless CMS. All filtering, querying, and data operations follow Directus conventions.
</Callout>

| Feature | Description |
|---------|-------------|

| **Pagination** | Built-in support for paginated results |
