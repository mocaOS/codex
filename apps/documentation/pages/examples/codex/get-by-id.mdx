---
title: Get by ID
description: Retrieve a specific codex item with all its details
---

import { API_BASE_URL } from "../../../constants";

Retrieve a specific codex item by its unique identifier. Replace `{id}` with the actual item ID.

<OpenPlaygroundButton
  server={API_BASE_URL}
  url="/items/codex/{id}"
  method="GET"
  pathParams={[
    { name: "id", defaultValue: "1" }
  ]}
/>

```bash
GET /items/codex/1
```

## With Specific Fields

You can also limit the returned fields:

<OpenPlaygroundButton
  server={API_BASE_URL}
  url="/items/codex/{id}"
  method="GET"
  pathParams={[
    { name: "id", defaultValue: "1" }
  ]}
  queryParams={[
    { name: "fields", defaultValue: "id,name,description,owner" }
  ]}
/>

```bash
GET /items/codex/1?fields=id,name,description,owner
```

<Callout type="info" title="Not Found Response" icon>
  If the item doesn't exist, the API will return a `404` status code with an error message.
</Callout>
